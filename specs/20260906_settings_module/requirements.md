# 设置模块需求规格

> 状态：已确认
> 日期：2026-09-06
> 阶段：Phase 1 已确认，进入 Phase 2 技术设计

## 背景与目标

在现有设置入口提供亮度、Wi-Fi 和 Codex 自动刷新周期配置。设备本地保存配置，重启后恢复；设置功能无需连接电脑。以本文件确认后的范围为准，不自动继承旧草稿的其他设置功能。

## 功能需求及验收标准

### R-01 设置入口与离线使用

- 保留现有顶栏及四模块，通过 Fn+4 或现有循环导航进入设置。
- 设置首页提供“屏幕亮度”“Wi-Fi”“Codex 自动刷新”三个入口，使用中文标签。
- BLE 未连接、断线或 Wi-Fi 失败时，仍可进入、编辑和保存设置。
- 验收：离线开机即可操作三个入口；操作中断开 BLE 不丢失已保存配置。

### R-02 五档亮度

- 提供且仅提供 5 个非熄屏档位，调整后立即改变实际屏幕亮度。
- 档位显示为 20%、40%、60%、80%、100%，首次默认 60%；百分比表示控制档位，不表示实测光学亮度。
- 每次调整自动保存，无额外保存按钮；相同值不重复写入。保存失败时保留当前亮度并提示“当前生效，保存失败”。
- 验收：五档均可辨识且不黑屏；成功保存后重启恢复该档位；失败时不得显示已保存。

### R-03 Wi-Fi 扫描与配置输入

- 支持扫描附近网络、选择 SSID 后填写，以及手动输入隐藏 SSID；扫描失败或无结果时仍可手动配置。
- 仅展示 SSID、用户名、密码，不展示网络类型选项。用户名可选：为空使用普通网络认证，非空使用公司网络认证。
- SSID、用户名、密码在编辑及已保存配置中均明文展示，不提供掩码或显示/隐藏开关；此要求覆盖旧草稿的密码隐藏规则。
- 支持大小写字母、数字、空格、键盘可输入符号及退格；输入期间 `; , . /` 等字符不得被当作列表导航。超长内容可滚动查看，不得悄悄截断实际值。
- 三字段在当前行编辑，长值随尾部光标横向滚动，不提供全文查看入口。主菜单保留三个字段、扫描网络、保存、测试连接和查看网络信息。
- 可扫描并保存中文 SSID；本期不新增中文输入法。
- 提交时校验必填项、字段格式及长度，失败后保留草稿并提示字段问题。具体长度及认证约束在设计阶段确定。
- 验收：扫描选择、手动隐藏 SSID、含大小写和符号的密码均可完成配置；公司网络用户名可填写、保存和回显。

### R-04 Wi-Fi 保存与开机恢复

- 本期仅保存一组网络配置，保存新配置覆盖上一组；编辑草稿和已保存配置明确区分。
- “保存”独立于“测试连接”：合法配置可以在网络不在附近时保存；保存仅更新本地配置，不启用 Wi-Fi、不尝试连接。
- 重启后只读取已保存网络；Wi-Fi 保持关闭，没有配置时显示未配置。采用固定 AUTO 按需策略，不增加模式选择：只有扫描或连接测试等明确需求才临时启用 Wi-Fi。本期提供模块可调用的配置检查、连接和关闭能力；未来具体联网业务再接入，本期不实现业务本身。
- 未保存草稿在本次开机切页后保留，重启后恢复已保存值；保存失败不得覆盖上一次有效配置。
- 验收：保存后重启回显相同字段，Wi-Fi 仍关闭；格式合法的错误密码可保存，只有主动测试时才显示连接失败；网络不可用时其他模块正常运行。

### R-05 Wi-Fi 连通性测试

- “测试连接”使用当前编辑的配置发起一次测试，不自动保存；可修改错误字段后再次测试。
- 成功口径为“完成 Wi-Fi 认证并取得有效 IP”，内部保留当次凭据用于变更比较，网络信息展示上次测试 IP 及结果，不展示凭据全文；不将此结果描述为公网可用。
- 展示扫描中、连接中、成功、失败或超时；仅在底层能够明确识别时显示具体失败原因，不把所有失败解释为密码错误。
- 单次扫描上限 15 秒、单次连接上限 30 秒；不允许重复点击产生并行扫描或连接。
- 切页不中断已启动的操作；扫描结束后关闭 Wi-Fi，连接测试无论成功、失败或超时均断开并关闭 Wi-Fi，不后台重连。保留测试结果供查看，明确该结果不是当前在线状态；重启只恢复配置，不自动连接。
- 验收：可用网络取得 IP 后结束测试并关闭 Wi-Fi；失败、超时及扫描结束也恢复关闭；结果可继续查看，设备静置不重新联网；操作期间仍能切页和通过 BLE 使用原有模块。

### R-06 Codex 自动刷新分钟配置

- 缺少配置时默认 5 分钟；已有合法配置优先，不因升级或进入设置被重置。
- 设置页直接调整整数分钟，范围 1～60，不进入下一级编辑页。停止调整 600 毫秒后自动保存，离开时补存；保存后即时生效并持久化，无保存按钮或独立状态查看入口。
- 复用设备现有 Codex 配置和调度能力，底层继续保存秒数，桌面端不下发或覆盖周期。
- 周期改变后从生效时刻等待完整新周期；相同值不重置计时。关闭自动刷新时保存不打开任务，在途请求继续完成。
- 现有串口允许非整分钟秒值：设置页如实显示“当前 90 秒”等原值，用户首次调整分钟后才覆盖，不自动取整写回。
- 本期只持久化刷新周期，不扩展 Fn+Enter 自动刷新开关的重启行为。
- 验收：保存 1、5、60 分钟并重启恢复；调整不越过上下限；在关闭自动和查询进行中修改周期符合上述语义。

### R-07 配置持久化与异常恢复

- 亮度、Wi-Fi、Codex 周期按模块保存，修改一项不重置其他模块配置。
- 开机缺少或损坏某项配置时，仅该项回退默认：亮度默认档、Wi-Fi 未配置、Codex 5 分钟；明确提示读写失败，运行中读取失败保留当前有效值。
- 保存须区分“已保存”“保存失败”“已保存但应用失败”，不得把文件保存结果与联网结果混为一谈。
- 文件系统异常不得自动格式化或擦除其他配置；沿用当前文件系统部署前提，并在后续操作文档说明首次部署方式。
- 验收：分别修改三项后断电重启恢复；模拟文件缺失、损坏和写失败时可继续使用设备，其他配置不受影响。

### R-08 公共 Wi-Fi 能力

- 向其他模块提供独立于设置页面的服务：检查已保存配置、判断当前能否发起连接、查询实际连接状态、按需连接、关闭 Wi-Fi。
- 配置检查不启用无线。明确区分“配置有效且允许尝试连接”与“实际连接成功”；真实连通性通过连接结果判断，历史测试成功不能保证当前可连。
- 模块连接默认使用已保存配置，采用非阻塞调用并提供进行中、成功、失败、超时结果；成功后保持连接供调用模块完成业务，模块结束时显式释放并关闭。
- 设置页测试复用同一连接能力，取得结果后自动释放；普通模块连接成功不自动关闭。当前没有业务调用时保持静默。
- 本期采用单一使用者互斥：已有扫描、测试或模块持有连接时，新请求返回忙，不抢占连接；关闭需要匹配本次请求身份，避免旧请求关闭新连接。
- 保存新配置不打断进行中的连接，下一次连接使用最新保存值；连接失败或超时自动清理并关闭，无后台重试。
- 验收：使用模拟调用模块完成“检查 → 连接 → 查询成功 → 使用期间保持 → 关闭”；覆盖无配置、忙、失败、超时、重复关闭及过期请求关闭；不要求新增真实联网业务。

## 非功能要求与验证边界

- 复用当前顶栏、配色、中文字体与按需重绘；长字段和错误信息在小屏上可查看。
- 扫描及连接不得用长时间等待阻塞输入、BLE 收发、Codex 刷新或授时。
- 保留 Fn 导航、现有 Alt 脚本快捷键和 Codex 页 Fn+Enter 的语义；文本编辑所需 Shift 不得被全局路由吞掉。
- 自动化验证覆盖配置校验、恢复、保存失败、分钟换算、输入路由及联网状态超时；界面、实际亮度、真实无线连接和断电恢复需要人工验收。
- 本需求中的公司 Wi-Fi 能力必须使用目标网络在 ADV 上验收，旧草稿中的 ESP32-C3 验证不代表 ADV 已支持该网络。

## 范围外

- BLE 配对/重连管理、设备版本页、恢复出厂设置、自动亮度。
- 多组 Wi-Fi 管理、删除配置界面、复杂漫游策略。
- 证书导入、EAP/Phase 2 手动选择、浏览器 Portal 登录。
- Wi-Fi 传输电脑业务、Wi-Fi 替代 BLE、NTP 和其他联网业务。
- 密码隐藏切换、中文输入法、桌面端远程配置设置页。

## 已确认结论

- 2026-09-06：用户确认公司 Wi-Fi 只需 SSID、账号、密码，无需证书；用户名同时作为 identity。
- 用户确认连接成功即测试成功，采用认证完成并取得 IP 的口径，不探测公网。
- 用户确认五档亮度及 Codex 1～60 分钟范围，其余文档建议按本次方案执行。
- 用户补充以 `/Users/naaran/Github/focus-clock/` 已成功连接公司网络的实现作为技术参考，配置界面仍在 ADV 上实现。

- 用户追加确认：去掉 Wi-Fi 类型展示，用户名决定认证方式；固定 AUTO 按需启用，保存和开机不连接，扫描/测试结束关闭 Wi-Fi。此结论覆盖先前自动连接及测试后保持连接的方案。

- 用户补充：本期须提供公共 Wi-Fi 配置检查、连接条件查询、连接和关闭能力，供后续模块直接调用。
