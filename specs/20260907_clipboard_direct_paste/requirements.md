# 剪贴板与直接粘贴模块需求

日期：2026-09-07。用户已确认需求，进入技术设计。

## 背景与目标

用户在电脑配置常用文本，在 ADV 选择条目后，由当前连接的电脑服务写入系统剪贴板并触发前台粘贴。直接粘贴是本次核心能力，单纯复制到剪贴板不算成功完成。

脚本与剪贴板共用一套动作核心，仅在 UI 按类型拆分为两个入口；配置、目录、快捷键、执行调度和反馈机制统一，实际执行时按动作类型调用脚本执行器或粘贴执行器。

## 功能需求

### R-01 平台与入口

- 首批交付 macOS 适配，预留 Windows/Linux 适配边界；本期不实现这两个平台。
- 上层统一调用粘贴能力，无需知道电脑系统；系统剪贴板、粘贴按键和权限差异由底层适配器处理。
- 保留四模块顶栏，Fn+3 进入剪贴板，Fn 左右切页沿用现状。
- 不增加设备编辑器、电脑弹窗或新的首页。

验收：从任意页进入剪贴板，其他模块和全局导航仍正常。

### R-02 电脑文本配置

- 复用电脑 actions 配置，支持 type=clipboard、唯一 actionId、name、可选 key、enabled、content 和空 params。
- content 为静态纯文本，原样保留首尾空格、中文、英文、换行、Tab 和常用 Unicode；禁止 NUL 与非法编码，不进行变量替换、命令执行或 shell 插值。
- 建议单条正文最多 8192 UTF-8 字节；条目总数不设业务上限。名称、ID、分页等具体约束在设计阶段与现有协议对齐。
- 禁用和非法条目不参与目录或执行；单项非法不阻塞其他条目和模块。重复 ID 报错隔离。
- 沿用修改配置后重启电脑服务并重连的生效方式。

验收：混合有效、禁用和非法项，仅有效启用项可见可执行；特殊字符与首尾空格不被修改。

### R-03 列表及视觉风格

- 参考脚本页：同一字体、配色、四行可见列表、圆角选中高亮、名称裁剪、右侧快捷提示和底部位置计数。
- 上下选择、跨页继续移动，Enter 粘贴；底部提示为“Enter 粘贴”。复用剪贴板模块的方向映射设置。
- 分页获取目录，ADV 仅缓存当前页元数据；正文和 params 不下发、不在设备持久化。
- 提供加载中、空目录、目录失败、能力不可用状态。目录加载失败时 Enter 仅重读目录，不顺带执行。

验收：超过两页的配置可访问全部条目；长中文名称不挤占提示；空列表和错误状态不触发旧条目。

### R-04 统一动作核心与快捷触发（已确认方向）

- 脚本与剪贴板共用动作目录、ID 执行入口、全局快捷键解析、忙碌调度和结果关联，不建设两套平行业务核心。两个 UI 按类型筛选目录、保留各自选择位置，并使用“执行”或“粘贴”等对应文案。
- 与脚本一致，使用任意页 Alt+字母触发剪贴板动作，普通字母不执行；不增加模块内裸字母触发。
- 脚本与剪贴板共用快捷键匹配顺序：按完整配置顺序，第一个有效启用的匹配项生效；后续重复键条目仍可通过列表执行，只给实际生效项显示快捷提示。
- 快捷键不依赖当前页和已缓存目录。Fn 导航、Codex 的 Fn+Enter 与设置文本编辑优先级保持现有规则。

验收：目标不在当前页时仍可触发；跨类型重名快捷键只执行首项；普通字母不粘贴。

### R-05 直接粘贴

- ADV 只发送配置项标识或快捷键，电脑从本机配置查找正文；请求不能覆盖正文。
- 每次执行先写入系统剪贴板，确认写入完成后，再发送 macOS 对应的粘贴操作到当时的前台窗口。
- 服务不主动打开、激活或切换窗口，不弹出业务确认框，不主动选择目标控件。
- 粘贴后保留新的系统剪贴板内容，不自动恢复旧内容。
- 不附加 Enter 或其他键，不自动提交表单；文本本身包含换行时仍原样粘贴。

验收：在文本编辑器、浏览器多行输入框和 IDE 编辑区分别粘贴中文、多行、特殊字符及首尾空格；焦点不被服务抢走。

### R-06 连续触发与并发（已确认忙时拒绝）

- 每次独立按下并释放生成一次新操作，长按不因扫描重复触发；发送失败、超时和重连均不自动重放。
- 统一动作核心沿用脚本的忙时拒绝方式：脚本和剪贴板共用一个执行槽，忙时新请求明确反馈“忙碌”，不排队。粘贴占用完整覆盖“写入 → 粘贴”。因此脚本执行中也拒绝新的粘贴请求，反之亦然。
- 上次完成后再次点击会再次粘贴相同内容。执行期间的点击不承诺全部粘贴，此项是对原草稿按连续点击次数全部执行的收敛。
- 剪贴板操作不阻塞 BLE 消息处理、Codex、授时或设备导航。

验收：并发请求不会出现 A 的请求粘贴 B 的正文；忙碌反馈明确；完成后可立即再次操作；其他模块仍能响应。

### R-07 执行反馈与失败

- 设备显示处理中、已发送粘贴、忙碌、失败或结果未确认，复用脚本式底部反馈。
- 成功仅代表剪贴板写入和系统粘贴操作已完成发送，不宣称已核实目标输入框内容。
- 剪贴板写入失败时不得继续发送粘贴快捷键；写入成功但粘贴失败时明确反馈失败，并说明文本仍在剪贴板。
- 对可检测的权限不足或系统调用失败返回明确原因；权限配置步骤放入操作说明。
- 超时或断线后结果无法判定时，不显示成功、不自动重试；不得假定已产生的系统副作用能够撤回。

验收：注入写入失败时粘贴调用为零；粘贴阶段失败不显示成功；超时无第二次执行。真实权限与目标应用行为另行人工检查。

### R-08 会话与模块隔离

- 离线显示公共等待连接画面，不执行粘贴；断线或切换电脑清空旧目录、请求和反馈。
- 重连重新获取当前电脑目录，不重放旧动作；迟到响应不能覆盖新会话。
- 不支持剪贴板的电脑显示能力不可用，不影响脚本、Codex、设置和系统授时。
- 电脑断线清理取消尚未完成的请求；已写入的剪贴板或已发送的粘贴不回滚。

验收：两份不同电脑配置依次连接，不出现旧条目；断线重连无自动粘贴，旧响应不能污染新状态。

## 非功能需求

- 延续现有分层和统一消息通道，OS 操作集中于适配器，不将文本伪装成脚本执行。
- 正常和详细日志都不输出正文、剪贴板旧内容或请求中的敏感文本；仅记录动作 ID、结果类别和耗时等诊断信息。
- 小屏只同步展示元数据；分页容量是传输约束，不是条目总数限制。
- 自动化验证覆盖新逻辑与既有脚本快捷键回归；构建不替代真实粘贴、BLE、中文显示和焦点验收。

## 使用边界

- 粘贴目标由操作发生时的前台窗口决定；期间切换焦点可能改变目标。
- 系统操作已发送，目标控件仍可能不接受粘贴；程序不能普遍检测输入框最终内容。
- 终端对多行粘贴的确认或执行行为由终端决定，本模块只负责原文粘贴，不主动追加提交键。
- 实际 macOS 权限路径、系统接口和支持条件在设计阶段核实，随后写入使用说明。

## 范围外

剪贴板历史、读取或同步电脑当前剪贴板、设备编辑正文、富文本/图片/文件、模板变量、动态日期、光标定位、多步键盘宏、自动寻找窗口、恢复旧剪贴板、配置热重载，以及本期 Windows/Linux 平台实现。
