# 脚本模块与全局快捷键：需求

## 背景与目标

实现顶部第二栏“脚本”，通过电脑端配置提供脚本列表及执行能力；统一系统快捷键、跨模块动作快捷键和页面按键优先级。首个测试动作使用默认浏览器打开 `https://google.com`，配置快捷键为 `g`，组合键为 `Alt+G`。

## 功能需求

### R-01：第二栏脚本模块

- 将脚本占位页替换为可用列表，按电脑端配置顺序展示有效且启用的脚本名称和快捷键；没有快捷键的脚本仍可从列表执行。
- 上/下移动选中项并使其保持可见，首尾停止、不循环；Enter 执行当前选中项，空列表 Enter 不发送请求。
- 显示目录加载、空列表、执行中、执行结果或错误；全局触发后在当前页面提供简短反馈，不强制切换到脚本页。
- 不设置脚本总条数上限，列表分页获取；设备无需保存完整目录。Alt 快捷键由电脑端在全部有效启用动作中匹配，不依赖当前页或目录是否已加载。连接或能力未就绪时提示不可用，不发送执行请求。
- 断线或电脑身份变化使旧目录与旧请求失效；重连后重新获取当前电脑动作。

### R-02：默认测试动作与电脑执行

- 在仓库默认 `desktop/config.json` 中增加启用的“打开 Google”脚本，`key` 为 `g`；仅显式触发时执行，不在启动或连接时自动打开。
- 由 macOS 电脑端执行配置中的脚本，默认测试内容相当于 `open https://google.com`。具体执行字段及解释器规则在设计阶段确定。
- ADV 从列表执行时发送已配置动作的标识，全局快捷键执行时发送对应字符；电脑以本机有效配置为准，不接受设备传入任意替代命令。
- 请求失败、无法启动、非零退出和超时可诊断；执行不阻塞其他模块和 BLE 会话。
- 浏览器启动命令成功只能表示系统接受打开请求；网络是否可达、网页是否加载成功由人工验证。
- 首版电脑配置修改后重启桌面服务并重连生效，不要求文件监视或在线编辑。

### R-03：系统 Fn 优先级最高

- 输入按以下顺序处理：Fn 系统组合键 → Alt 全局动作 → 当前模块方向映射 → 当前模块普通按键。
- 只要包含 Fn，先交系统层；仅显式放行 Codex 页的 Fn+Enter 特例，其他未知 Fn 组合不降级触发 Alt 动作、普通字符或页面 Enter。
- Fn 系统键在任意模块、加载/执行状态和未连接状态均进入系统分发；涉及电脑的操作仍须满足连接条件。
- Fn+1/2/3/4 分别切换 Codex/脚本/剪切板/配置；本次维持四栏，Fn+5 不切换页面。
- 保留现有 Fn+左/右循环切换现有栏目；普通方向键只交给页面。
- Fn+Enter 保留为 Codex 页内开关自动刷新，其他页面不响应，不提升为全局快捷键。

### R-04：Alt 全局动作与匹配顺序

- 在任意模块按 Alt+配置字符直接执行对应动作；例如 Alt+G 打开 Google，无须先访问脚本页。
- 快捷键在全部可快捷执行的动作间共享命名空间，包含脚本和后续剪切板/粘贴动作，建议配置不重复；如重复，按整个配置顺序匹配第一条功能，不按当前模块优先。
- 首版只接受单个英文字母，大小写统一；`g` 与 `G` 视为相同。`key: null` 表示不绑定。
- 重复快捷键是可接受配置，不拒绝条目、不清除后续条目的 key；匹配时只执行第一条有效且启用的功能，后续条目仍可从列表选择执行。无效、禁用项不参与匹配。
- Alt+未绑定键不触发动作，也不降级为页面输入；Fn+Alt 由 Fn 层优先处理。Ctrl 等额外修饰键不应意外匹配 Alt 动作。
- 在脚本、剪切板、配置页直接按 `g` 等普通字母不得执行动作；Codex 页也不引入普通字母直接执行功能。
- 每次组合键按下只触发一次，长按、组合中追加/松开按键不能重复提交同一次动作；再次执行需重新按下。

### R-05：每模块可配置的方向映射

- 没有修饰键时，`;`、`,`、`.`、`/` 分别映射上、左、下、右；映射前先完成系统与 Alt 分发。
- 每模块可独立开启/关闭，不使用单一全局开关；Codex 和脚本默认开启。
- 剪切板、配置的方向映射默认也开启，形成一致的列表操作习惯；未实现页面暂不产生业务效果。
- 关闭后这些字符不再触发方向动作；是否作为字符使用由所属页面决定。左右方向没有对应页面操作时不产生其他动作。
- 映射设置属于 ADV 模块配置，缺省保持默认兼容；提供明确修改、生效与重启保留方式，沿用现有本地配置能力，具体入口在设计阶段明确。

### R-06：模块内操作与后续页面约定

- Codex 页无修饰 Enter 重新查询用量，上/下滚动现有窗口；保持已有请求忙碌保护和后台刷新行为。
- 脚本页上/下选择，Enter 执行；剪切板页上/下选择，Enter 确认对应粘贴动作；配置页上/下选择，Enter 确认或进入当前项。
- 剪切板和配置页的上述规则作为共同输入约定；本次不实现其业务页面和粘贴执行。

### R-07：执行与兼容边界

- 列表 Enter 与 Alt 走同一动作执行入口。脚本执行采用单个在途槽：忙碌时明确提示，不排队、不重复提交，也不影响 Codex/授时。
- 超时或断线后不自动重试执行；结果未知时应说明未确认结果，不能假定电脑没有执行。迟到响应不能更新其他动作或新会话。
- 旧电脑端未声明脚本能力时显示不可用，Codex 和授时继续按已有能力工作。
- 保留顶部导航与中文页面风格，不新增侧栏。错误配置不能拖垮有效动作和基础连接能力。

## 验收标准

| 场景 | 预期 |
| --- | --- |
| 默认配置、连接完成、Fn+2 | 看到“打开 Google”和 Alt+G；无须修改配置 |
| 脚本页选中 Google 后 Enter | 电脑默认浏览器接受打开请求；设备显示执行结果 |
| Codex、脚本、剪切板、配置各页 Alt+G | 同一动作执行一次，保留当前栏目并反馈 |
| 各页单独按 g | 不执行 Google 动作 |
| Fn+数字、Fn+Alt+G、未知 Fn 组合 | 系统优先；不泄漏为脚本或页面操作 |
| 默认 Codex/脚本页按 ; , . / | 分别收到上/左/下/右；有对应操作才改变页面 |
| 单独关闭一个模块映射并重启 | 仅该模块不再映射，其他模块保持原配置 |
| 重复 g/G、禁用项、无绑定项 | 重复配置可加载；快捷键只执行第一条有效启用项，无绑定项可从列表执行 |
| 长按、修饰键先后变化、执行中再次触发 | 不因同一次按键重复执行；忙碌提示正确 |
| 执行失败、超时、断线重连、迟到结果 | 提示符合实际，不自动重放，旧会话数据不污染新会话 |
| 多行列表、跨页、首尾、空列表 | 选中与滚动正确，无越界或空项执行 |
| 超过 16 条及多页脚本，目标不在当前页 | 所有有效脚本可浏览执行；Alt 仍在电脑端全量匹配第一条 |
| Codex Enter 与后台任务 | 手动查询和跨页自动刷新、授时无回归 |

自动化覆盖配置、路由优先级、目录/请求关联和假执行器成功/失败/超时；真机覆盖物理按键组合、中文列表、BLE 和浏览器打开。不以构建或模拟执行代替人工验收。

## 范围外

- 剪切板业务及自动粘贴、完整配置页面、第五业务模块。
- Windows/Linux 执行适配、电脑侧全局热键监听、配置热更新、脚本编辑器、终端交互、任务编排和执行历史。
- 新增周期任务、重构 Codex/授时调度、依赖升级或自动刷写。

## 待确认问题

无。用户进一步确认不限制脚本条数，采用分页列表和电脑端全局快捷键匹配。此前已确认：维持四栏；Fn+Enter 不提升为全局，保留 Codex 页内行为；本次仅实现脚本模块；建议快捷键不重复，重复时默认执行第一条匹配功能。
