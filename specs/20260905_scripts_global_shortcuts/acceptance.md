## 人工准备

1. 按 [根 README](../../README.md) 自行构建并刷写固件，启动桌面服务；本轮未执行 upload 或 uploadfs。
2. 首次配置存储需部署 LittleFS，已有文件系统可直接用串口 save 创建 `/config/input.json`，无需重新 uploadfs。uploadfs 会覆盖整个分区，自定义文件需先备份；普通 upload 不等于部署配置。
3. 先用默认 `desktop/config.json` 检查 Google；其命令退出成功仅表示系统接受打开请求，网页加载另行观察。
4. 多页检查时停止默认桌面服务，再从项目根目录执行：

   ```sh
   cd desktop
   uv run --locked adv-workdeck --config ../specs/20260905_scripts_global_shortcuts/manual-config.json --verbose
   ```

   [manual-config.json](manual-config.json) 保留 Codex，含 17 个脚本；不会打开浏览器。显式执行多数条目会追加一行到 `/tmp/adv-workdeck-script-acceptance.log`。每次检查比较新增行，不把旧日志当成本次结果。

| 条目 | 行为与用途 |
| --- | --- |
| 01、09 | 都绑定 g；Alt+G 只能新增 script-01，选中 09 后 Enter 新增 script-09 |
| 17 | 绑定 z；尚未进入脚本页时 Alt+Z 也应新增 script-17 |
| 14 | 等待 5 秒后新增 script-14，用于忙碌和执行中切页 |
| 15 | 等待 3 秒，配置超时为 1 秒；预期超时且不新增 script-15 |
| 16 | `exit 7`，用于非零退出反馈 |
| 其余 | 无快捷键，Enter 可执行并记录对应编号 |

配置变更后重启桌面服务并重连，避免把上一会话目录当作新配置。结束后停止验收服务，用默认配置重新启动；映射改动可用 `input.config.save {}` 恢复全开。
