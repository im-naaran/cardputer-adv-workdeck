# CPU 档位阶段验收记录

> 状态：task-02～task-04 代码及自动化已记录；人工验收待确认

日期：2026-09-11。本记录仅覆盖 CPU 功能，不代表自动 Light-sleep、功耗收益或生产可用。

## 本轮实现

- 应用启动默认 160 MHz；ROM/bootloader 频率不作保证。读取 `/config/power.json` 后，在 BLE 初始化前应用持久化档位。
- 配置格式 `{"cpuFrequencyMhz":160}`，只允许整数 80/160/240。缺失或非法输入使用默认值，启动不写文件；读取错误可见，保存时不能覆盖无法读取的文件。
- Fn+4 设置首页新增第五项“CPU频率”，四行滚动。方向键调档，Tab 循环，即时应用并保存；Enter 在失败时重试。显示硬件读回频率，失败保留目标档位及错误信息，返回/重入不清除。
- 当前平台仅支持固定频率。自动睡眠请求及 PM 构建返回不支持，启动串口报告 `automatic_sleep=unsupported`。

实际构建环境仍为 espressif32 6.7.0、Arduino 2.0.16 / IDF 4.4.7；构建输出已变为 160 MHz。Arduino 初始化源码通过 F_CPU 调整应用启动频率，应用后续改频只调用 PowerAdapter。依赖未升级。首次构建因 PlatformIO 全局锁写权限失败，使用授权的沙箱外构建重试完成。

这些用例使用平台替身和真实业务代码，不证明板上 CPU/APB、BLE、画面、真实 Flash 或功耗效果。目标板编译仅证明真实接口可编译链接。本轮未烧录或执行 uploadfs。
