# CPU 档位与开机自动 Light-sleep：任务清单

> 状态：已确认

日期：2026-09-11。依据已确认的 [需求](requirements.md) 和 [设计](design.md)。用户要求继续本任务，确认清单并进入 Phase 4；完成情况见勾选与执行记录。

## 执行规则

- 清单确认后才进入编码，依赖任务完成后才能执行后续任务。
- task-02～task-06 可在当前 SDK 下完成 CPU 功能和期限逻辑，不代表 Light-sleep 已完成。
- task-07 必须取得真实 SDK/BLE 睡眠证据，才允许后续睡眠集成。缺设备或能力不足时保持未完成，继续不依赖该门槛的工作。
- 具体迁移、依赖升级遵循已确认设计的授权边界，先给出版本、差异、影响及回退方案，不修改依赖缓存。
- 每项保持可单独审阅和回退的差异，回退只撤销本任务改动。配置保持兼容，不执行 uploadfs，不创建提交。
- 自动化、构建和实机结果分别记录；人工验收未确认不宣称生产可用。
